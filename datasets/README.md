# datasets

Los datasets **no se versionan** (son muy pesados: CICIoT2023 tiene decenas de GB).

Aquí solo van scripts de descarga/preparación:
- `download_ciciot2023.py` — descarga y organiza CICIoT2023
- `download_iot23.py` — descarga y organiza IoT-23
- `explore.ipynb` — exploración inicial (Fase 2 de CRISP-DM: Comprensión de los datos)

La carpeta `raw/` (datos crudos) y los `.csv` están excluidos en `.gitignore`.
