# datasets

Los datasets no se versionan (son muy pesados: CICIoT2023 tiene decenas de GB).

Aqui solo van scripts de descarga/preparacion:
- `descargar_ciciot2023.py` — descarga y organiza CICIoT2023
- `descargar_iot23.py` — descarga y organiza IoT-23
- `explorar.ipynb` — exploracion inicial (Fase 2 de CRISP-DM: Comprension de los datos)

La carpeta `crudo/` (datos sin procesar) y los `.csv` estan excluidos en `.gitignore`.
